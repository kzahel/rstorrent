RSTorrent for ChromeOS Linux

ChromeOS Linux runs the Rust torrent engine and serves the complete RSTorrent interface to Chrome. This extension provides the handoff; it cannot wake a fully stopped Linux environment by itself.

Install the preview

  1. Enable Linux development environment in ChromeOS Settings.
  2. Extract the RSTorrent Crostini package in Linux files.
  3. Open Terminal in that folder and run ./install.sh.
  4. Open RSTorrent for ChromeOS Linux from the Chromebook Launcher. It wakes Linux, starts RSTorrent, and returns to Chrome.

Everyday launch

Use the Chromebook Launcher when Linux may be stopped. Once the local backend is running, this extension’s ChromeOS Linux button opens or focuses its UI. Closing the tab does not stop active torrents.

Files and recovery

Downloads initially use Linux ~/Downloads. To use a Chromebook folder, choose Share with Linux in the Files app before adding it in RSTorrent.

Check the installed backend
rstorrent-crostini status
Restart the backend
systemctl --user restart com.jstorrent.rstorrent.crostini.service
Remove app files, keep profile and downloads
rstorrent-crostini uninstall
Also remove the Crostini profile
rstorrent-crostini uninstall --purge
