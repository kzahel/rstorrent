Status: Active, 2026-10-08. Bounded qualification follow-up to 259/274.

Topics: `desktop-jstorrent-replacement`, `web-ui-design`.

## Scope and stopping condition

The historical signed ARM AppImage passes real migration/preservation but its
successor window regions remain near black in native recordings. Its isolated
empty first-use rendering works. Cause and visual acceptance remain open.

Compare the same historical source/run/attempt's original-root-signed ARM Debian
payload using installed guest libraries. Verify actual package bytes and its
existing signature before boot. Extract with installed dpkg-deb into an owned
root, run its actual native binary/sidecar through the real old-writer helper,
and inspect actual migrated/restarted native recordings. Normal HOME/config/
data/cache discovery and all migration/refusal/payload invariants remain.

Stop after a bounded actual comparison, or concrete package/interface refusal,
with exact package/driver identities, native effects, restored state, owned
recording/root/metadata cleanup, verified shutdown and released claim. A usable
Debian payload does not qualify AppImage pixels, final source, package-manager
installation, auto/GUI updating or store/public delivery.

## Ownership and limits

The project rehearsal owns package-format selection and real legacy fixtures.
Machine Control owns the claim, guest transport, native UI and lifecycle. All
child processes remain registered with the helper's existing process-group
cancellation/restoration. Default AppImage behavior is unchanged. Debian mode
is Linux-only and manual/extracted-only; updater trials refuse before mutation.
Require matching Debian Architecture before creating/restoring any app scopes.

Use installed dpkg-deb without installing dependencies or running package
scripts. Preserve the original application installation and fixture scopes.
Use a twenty-five-minute lease and fifteen-minute execution bound after launch,
five-second default native recordings and existing bounded calls. Prepare
everything before boot; serialize cleanup before shutdown and claim release.
No graphics flags, permission edits, package graph, product policy, production
artifact, signing root, publication or iOS change.

## Validation

Read the existing public real old-writer helper, its architecture-pin tests,
native-host sibling-path selection and recorded original-signed inventory.
Add focused refusal tests for wrong platform, architecture and updater mode;
do not infer signature validity from a filename or source label. Record actual
Debian package/binary hashes, normal native Quit, source/payload preservation
and independent native frames. Existing product build baselines remain valid.
